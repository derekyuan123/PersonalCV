# Personal CV

My personal CV, built as a website.

**Live:** [derekyuan.co.uk](https://www.derekyuan.co.uk)

## About

A single-page site covering my education, projects, skills and certifications. I'm a student developer at The Perse School in Cambridge, mostly working on backend web development, algorithms and tooling.

## Tech stack

| Layer | Tech |
|---|---|
| Framework | React with TypeScript |
| Build | Vite |
| Package manager | Bun (npm also works) |
| Hosting | Vercel |

## Getting started (Why are you cloning this??)

```bash
git clone https://github.com/derekyuan1000/PersonalCV.git
cd PersonalCV
npm install
npm run dev
```

Open the local URL printed in the terminal.

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run lint` | Run ESLint |
| `npm run format` | Format with Prettier |
